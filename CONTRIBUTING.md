# Contributing feedback

Everyone with a GitHub account can use this public repository's issue forms to report a bug or suggest an improvement. Describe the page, what you expected and what happened, using invented examples. Device and browser details help reproduce problems.

All issue text and attachments are public. Do not upload credentials, account tokens, journal exports, recordings or private calendar information. For a security concern, do not post exploit details or secrets in a public issue; use the app's private support email-draft option.

You may propose changes through a pull request when applicable. Only authorized maintainers can merge or publish changes. The app's development source is maintained separately; this repository is for website distribution and feedback.

Public visibility is not a grant of a new open-source license. Any third-party runtime assets distributed later retain their respective license notices. A source-code licensing decision can be made separately by the owner.
